# E-Commerce
E-Commerce is a modern Android application designed for online shopping. It enables users to browse products, explore categories, view special offers, manage their shopping cart, and authenticate securely.

# Libraries and technologies used
- Navigation component : one activity contains multiple fragments instead of creating multiple activities.
- Dagger Hilt : dependency injection framework to manage app dependencies cleanly.
- Firebase (Auth & Firestore) : user authentication (Email, Google, Facebook) and cloud data storage.
- Retrofit : making HTTP connection with the REST API and convert JSON objects to Kotlin models.
- MVVM & LiveData : separate logic code from views and save state in case of configuration changes.
- Coroutines & Flow : run asynchronous code in the background smoothly.
- View Binding & Data Binding : bind views directly without inflating them manually.
- Jetpack Compose & XML : building modern reactive UI components alongside traditional XML layouts.
- Glide & Coil : cache images and load them efficiently into image views.
- DataStore & Protobuf : local data storage and preference management.
